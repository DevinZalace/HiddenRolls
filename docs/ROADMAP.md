# Hidden Rolls Roadmap

## Vision

Hidden Rolls is a companion application and hardware ecosystem that allows
Dungeon Masters and players to privately view physical dice rolls made inside
a connected, camera-equipped ornate dice tray.

## How This Roadmap Works

The roadmap is organized into seven high-level epics. Each bullet beneath an
epic represents a planned GitHub Issue. Detailed requirements and acceptance
criteria will live in the repository's Issues tab.

---

## Epic 1: Foundation

Establish the technical structure required to build and maintain the
application.

- **Issue:** Verify project setup and builds
- **Issue:** Establish application architecture
- **Issue:** Implement settings management
- **Issue:** Implement application state management

## Epic 2: Camera System

Create the connection between the mobile application and the camera inside the
Hidden Rolls dice tray.

- **Issue:** Connect the application to the ESP32 camera
- **Issue:** Display the live camera stream
- **Issue:** Handle camera disconnections and reconnection

## Epic 3: Dice Tray Experience

Build the central experience of privately viewing physical dice rolls.

- **Issue:** Create the dice viewing interface
- **Issue:** Capture and review still images
- **Issue:** Add dice tray lighting controls

## Epic 4: Mobile UI

Create the primary screens and navigation used to operate Hidden Rolls.

- **Issue:** Create the home screen
- **Issue:** Create the settings screen
- **Issue:** Create the about screen
- **Issue:** Add a connection status widget

## Epic 5: Hardware

Support the physical components and configuration of the Hidden Rolls dice
tray.

- **Issue:** Add battery level monitoring
- **Issue:** Create the Wi-Fi setup process
- **Issue:** Define the firmware update process

## Epic 6: Polish

Improve the clarity, accessibility, and visual consistency of the finished
experience.

- **Issue:** Add loading animations
- **Issue:** Create the application icon set
- **Issue:** Define the application color palette
- **Issue:** Improve application accessibility

## Epic 7: Documentation

Create the instructions and reference material needed to build, operate, and
maintain Hidden Rolls.

- **Issue:** Add setup and usage instructions to the README
- **Issue:** Create the application build guide
- **Issue:** Create the ESP32 setup guide
- **Issue:** Create the release checklist
